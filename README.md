# 📚 Estrutura de Dados 2

Repositório dedicado aos exercícios, atividades e códigos desenvolvidos durante a disciplina de **Estrutura de Dados 2**.

## 🎯 Objetivo

Aprofundar os conhecimentos em estruturas de dados e algoritmos, explorando técnicas para organizar, processar e manipular informações de maneira eficiente.

## 💻 Conteúdos

- Estruturas de dados avançadas
- Árvores e árvores binárias
- Tabelas hash
- Algoritmos de busca e ordenação
- Filas de prioridade e heaps
- Grafos e suas aplicações
- Análise de complexidade de algoritmos
- Exercícios práticos de programação

## 🛠️ Tecnologias

- Linguagem C
- Visual Studio Code
- Git e GitHub

## 📂 Organização

O repositório reúne códigos, exercícios e atividades desenvolvidos ao longo da disciplina, organizados conforme os conteúdos estudados.
